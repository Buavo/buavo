I'm a developer, hacker, and creator passionate about building tools that give power back to the user. Currently developing **PhantomLinux** — a custom Linux operating system built for gamers, security researchers, and privacy enthusiasts.

## 🔥 Current Project

### PhantomLinux Beta v1.0
> A custom Linux OS built from the ground up. Dark. Fast. Private. Powerful.

- 👻 Full hacker aesthetic with matrix themed visuals
- 🎮 Complete gaming suite — Steam, Lutris, Bottles, Wine, MangoHud
- 🔒 Professional security toolkit — Metasploit, Wireshark, Nmap, and more
- 🛡️ Privacy first — Tor, ProxyChains, KeePassXC built in
- ⚡ PhantomBoost Extreme Mode — exclusive one click overclock feature
- 🤖 PhantomAI — locally hosted AI assistant, fully private
